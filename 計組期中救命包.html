01效能計算（Chap1）

只要記 4 條公式。所有題目都是把數字代進去。

CPU 時間 = IC × CPI ÷ clock rateIC = 指令數。clock rate 用 Hz（1.2 GHz = 1.2×10⁹）。
clock rate = 1 ÷ cycle time1 ns ⇔ 1 GHz，0.5 ns ⇔ 2 GHz。
平均 CPI = Σ（比例 × 該類 CPI）例：40%×1.3 + 40%×1 + 20%×x
MIPS = clock(MHz) ÷ CPI = IC ÷ (時間 × 10⁶)小技巧：clock 換成 MHz（1.2 GHz = 1200），10⁶ 就自動消掉。
MFLOPS = clock(MHz) ÷ CPI(FP)老師題目上寫的定義。110 年用這個算拿滿分。
X 比 Y 快 n 倍：n = 時間Y ÷ 時間XSpeedup = 改善前時間 ÷ 改善後時間。永遠是「大的時間除以小的時間」。

題型 A：兩個編譯器（給 IC 和 MIPS 或時間）

  1. (a) 求 CPI：給 MIPS 就用 CPI = clock(MHz) ÷ MIPS；給時間就用 CPI = 時間 × clock ÷ IC。
  2. (b) 「MIPS 相同」：MIPS = f ÷ CPI 相同 → fA ÷ fB = CPI_A ÷ CPI_B。
    「執行時間相同」：IC×CPI÷f 相同 → fA ÷ fB = (IC_A×CPI_A) ÷ (IC_B×CPI_B)。
  3. (c) 新編譯器快多少：三個時間都算出來（都用原本的 clock），再用「舊時間 ÷ 新時間」。結果小於 1 就要寫「新的比較慢」。
113 期中 Q1 · clock 1.2 GHz
A：IC 1.2×10⁹、MIPS 1250；B：IC 10⁹、MIPS 800
(a) CPI_A = 1200 ÷ 1250 = 0.96      CPI_B = 1200 ÷ 800 = 1.5
(b) MIPS 相同 → fA/fB = 0.96 ÷ 1.5 = 0.64
    → A 的 clock 只有 B 的 0.64 倍（B 的 clock 快 1.5625 倍）
(c) 新：0.9×10⁹ × 1.4 ÷ 1.2×10⁹ = 1.05 s
    A ：1.2×10⁹ × 0.96 ÷ 1.2×10⁹ = 0.96 s
    B ：10⁹ × 1.5 ÷ 1.2×10⁹     = 1.25 s
    對 A：0.96 ÷ 1.05 = 0.914 → 新的反而比 A 慢
    對 B：1.25 ÷ 1.05 = 1.19 倍快

題型 B：MFLOPS 表格求 x、y

  1. 總 cycle 數 = 執行時間 × clock rate。
  2. 平均 CPI = 總 cycle ÷ IC。
  3. 列式：平均 CPI = 比例₁×CPI₁ + 比例₂×CPI₂ + 比例₃×CPI₃，把未知數解出來。
  4. MIPS = clock(MHz) ÷ 平均 CPI；MFLOPS = clock(MHz) ÷ CPI(FP)。
113 期中 Q2 · clock 2.5 GHz
A：IC 1.5×10¹⁰，L/S 40% FP 40% Br 20%，CPI 1.3 / 1 / x，時間 7.5 s
B：IC 3.2×10¹⁰，L/S 50% FP 40% Br 10%，CPI y / 0.8 / 1.4，時間 13.44 s
A：7.5 × 2.5×10⁹ = 1.875×10¹⁰ cycles → CPI = 1.875×10¹⁰ ÷ 1.5×10¹⁰ = 1.25
   1.25 = 0.4×1.3 + 0.4×1 + 0.2x = 0.92 + 0.2x → x = 1.65
B：13.44 × 2.5×10⁹ = 3.36×10¹⁰ → CPI = 3.36 ÷ 3.2 = 1.05
   1.05 = 0.5y + 0.4×0.8 + 0.1×1.4 = 0.5y + 0.46 → y = 1.18
(b) MIPS_A = 2500 ÷ 1.25 = 2000     MFLOPS_A = 2500 ÷ 1   = 2500
    MIPS_B = 2500 ÷ 1.05 ≈ 2381     MFLOPS_B = 2500 ÷ 0.8 = 3125

題型 C：多種指令類別、兩台機器比快慢

  1. 每台機器算平均 CPI（比例 × CPI 加總）。題目給「A 是 B 的 2 倍」這種，就設 B = x 再全部用 x 表示。
  2. 每指令平均時間 = 平均 CPI ÷ clock(GHz)，單位 ns。IC 一樣時直接比這個就好。
  3. 時間小的比較快。快幾倍 = 大 ÷ 小。

題型 D：Speedup（只改善某一部分）

  1. 先算出每一類的「時間」或「cycle 數」= 指令數 × CPI。題目直接給秒數就直接用。
  2. 「最高 speedup」：把能改的那一類變成 0，Speedup = 原總時間 ÷ 剩下的時間。
  3. 「能不能減少 25%」：要減掉的量 = 25% × 總時間。那一類的時間比要減的量少，就回答「不可能」。
  4. 「改善 CPI，但指令數變 1.4 倍」：設新 CPI 為 c，列式「新總 cycle = 0.9 × 舊總 cycle」解 c。
110 期中 Q3 · MUL 6、ADD 10、L/S 8、Branch 3（×10⁶），CPI 2 / 1 / 4 / 2
總 cycle = 6×2 + 10×1 + 8×4 + 3×2 = 12 + 10 + 32 + 6 = 60 (×10⁶)
(a) L/S 變 0：60 ÷ (60 − 32) = 60 ÷ 28 ≈ 2.14
(b) MUL+ADD 換成一個 MAC（CPI 2.4），換 n 組：
    每換一組 cycle 變化 = −2 − 1 + 2.4 = −0.6
    要少 4%：0.04 × 60 = 2.4 → 0.6n = 2.4 → n = 4
    → MUL 和 ADD 各換掉 4×10⁶ 個

題型 E：謬誤（Fallacy）

  1. 把兩台的 CPU 時間都算出來。
  2. 看題目說的指標（clock 最高、MIPS 最高、指令數最多）是不是剛好對應到時間最短。
  3. 寫結論：「此例中 ___ 高的是 P_，但 P_ 時間較短，所以此說法不成立（或此例剛好成立）」。
112 期中 Q3 · P1 4 GHz、CPI 1.4、IC 5×10⁹；P2 3 GHz、CPI 0.9、IC 10⁹
P1 = 5×10⁹ × 1.4 ÷ 4×10⁹ = 1.75 s      P2 = 10⁹ × 0.9 ÷ 3×10⁹ = 0.3 s
(a) clock 高的是 P1，但 P2 比較快 → 不成立
(b) P1 跑 10⁹ 個要 10⁹×1.4÷4×10⁹ = 0.35 s
    P2 在 0.35 s 能跑 0.35 × 3×10⁹ ÷ 0.9 ≈ 1.17×10⁹ 個
(c) MIPS_P1 = 4000 ÷ 1.4 ≈ 2857，MIPS_P2 = 3000 ÷ 0.9 ≈ 3333
    P2 MIPS 高，P2 也比較快 → 此例成立
112 期中 Q4 · 舉例 MIPS 和效能反過來
同一台 4 GHz 機器，同一個程式用兩個編譯器：
編譯器 1：10×10⁹ 個指令，CPI 1 → 時間 2.5 s，MIPS = 4000
編譯器 2：2×10⁹ 個指令，CPI 2  → 時間 1 s，  MIPS = 2000
編譯器 2 的 MIPS 比較低，卻比較快 → MIPS 和效能反向
陷阱
  • 「cycle time 1 ns」要先轉成 clock rate 1 GHz 再算。
  • 比例是 40% 就用 0.4，不要忘記乘。
  • 「快幾倍」一定是大時間 ÷ 小時間，所以答案一定 ≥ 1。

02進位轉換、2 補數、Excess

萬用法：任何進位先轉成十進位，再轉成目標進位。只有 2、4、8、16 之間可以抄捷徑。

任何進位 → 十進位

(d₂d₁d₀.d₋₁d₋₂)ₖ = d₂k² + d₁k¹ + d₀ + d₋₁/k + d₋₂/k²A=10、B=11、C=12。例：(3A)₁₃ = 3×13 + 10 = 49
(.343)₆ = 3/6 + 4/36 + 3/216 = 135/216 = 0.625小數部分化成分數最準。

十進位 → 任何進位

  1. 整數部分：一直除以 k，記餘數，由下往上讀。
    296 ÷ 11 = 26 餘 10(A)，26 ÷ 11 = 2 餘 4，2 ÷ 11 = 0 餘 2 → (24A)₁₁
  2. 小數部分：一直乘以 k，取整數部分，由上往下讀。
    0.625×2 = 1.25 → 1；0.25×2 = 0.5 → 0；0.5×2 = 1.0 → 1 → .101

捷徑：2 ↔ 4 ↔ 8 ↔ 16

  1. 每一位拆成 bits：4 進位一位 = 2 bits，8 進位 = 3 bits，16 進位 = 4 bits。
  2. 從小數點往左右兩邊重新分組，不夠的補 0。
113 期中 Q4(b) · (−2310.102)₄ 轉 8 進位
4 進位每位拆 2 bits：2310.102 → 10 11 01 00 . 01 00 10
重新 3 個一組：      10 110 100 . 010 010
                     2   6   4  .  2   2
答案：(−264.22)₈

Excess（偏移）表示法

存的 bits = 真正的值 + NExcess 32 用 6 bits，Excess 64 用 7 bits。
真正的值 = 存的 bits − N例：Excess 32 (010011)₂ = 19 − 32 = −13 → (−23)₅

2 補數（用最少 bits）

  1. 先寫正數的二進位，最前面補一個 0（符號位）。
    18 → 10010 → 010010
  2. 要負數：全部 0↔1 反轉，再在最右邊那一位加 1（有小數就加在最後一個小數位）。
    010010 → 101101 → +1 → 101110 = −18
  3. 檢查：k bits 能表示 −2k−1 ~ 2k−1−1。−18 用 6 bits（−32 ~ 31）剛好。
113 期中 Q4(e) · (−154.213)₆ 轉 2 補數
轉十進位：1×36 + 5×6 + 4 = 70；.213₆ = 2/6 + 1/36 + 3/216 = 81/216 = 0.375
70.375 = 1000110.011 → 加符號位：01000110.011
反轉：10111001.100
最後一位 +1：10111001.101
答案：(10111001.101)₂
陷阱
  • 有小數的負數不能整數、小數分開轉。−19.25 ≠ (−19) 的補數接上 .01。一定要整串反轉再加 1。
  • 剛好是 −2k−1（像 −16）只要 k bits：−16 = 10000，不用 6 bits。
  • 2 補數讀回十進位：最左邊那一位的權重是負的。1010011 = −64 + 16 + 2 + 1 = −45。

bits → 數值

  1. 看第一個 bit：0 正、1 負。
  2. 8 個指數 bits 轉十進位得 E。
  3. E 在 1~254：答案 = ±1.fraction × 2^(E−127)，fraction 後面的 0 全部刪掉。
  4. E = 0：答案 = ±0.fraction × 2⁻¹²⁶（denormalized，前面是 0. 不是 1.）。

  2. e ≥ −126：指數 = e + 127 寫成 8 bits；fraction = xxx 後面補 0 到 23 位。

計數題、gap、範圍（每年必考一題）

能表示幾個不同實數 = 2³² − 2²⁴ − 1總共 2³² 種；扣掉指數 255 的（∞ 和 NaN）2 × 2²³ = 2²⁴ 種；+0 和 −0 是同一個數，再扣 1。
拆開寫 = 2×254×2²³ + 2×(2²³−1) + 1normalized + denormalized + 零。109 年問「normalized 和 denormalized 總數（含 0）」就是這個。
指數為 e 時，相鄰兩數的 gap = 2^(e−23)因為 fraction 有 23 位，最後一位的大小是 2⁻²³。
最小 normalized gap = 2⁻¹²⁶⁻²³ = 2⁻¹⁴⁹e = −126 時。
最大 normalized gap = 2¹²⁷⁻²³ = 2¹⁰⁴e = 127 時。
正 denormalized 範圍：2⁻¹⁴⁹ ~ 2⁻¹²⁶ − 2⁻¹⁴⁹最小 0.00…01 × 2⁻¹²⁶，最大 0.11…1 × 2⁻¹²⁶。
正 normalized 範圍：2⁻¹²⁶ ~ (2 − 2⁻²³) × 2¹²⁷1.0 × 2⁻¹²⁶ 到 1.11…1 × 2¹²⁷。
陷阱
  • denormalized 的指數是 −126，不是 0 − 127 = −127。
  • 算「有幾個數」時正負都要算，109 年考卷上只算正的那半被扣分。
  • 2⁻¹²⁴ 是 normalized：−124 + 127 = 3 → 00000011，fraction 全 0。

04Guard / Round / Sticky 捨入

題目給幾位小數，答案就留幾位小數。計算時多留 3 位：G、R、S。

G = 保留位數後第 1 位，R = 第 2 位直接抄數字。
S = 後面全部縮成一位：有任何非 0 就寫 1，全 0 寫 0例：0.006403 留 3 位 → 0.006 | 4 0 | 3 → S = 1 → 寫成 0.006401

加減法 SOP

  1. 對齊：指數小的那個往右移（差幾次方就移幾位），指數改成大的。
  2. 截斷：移完後只留「原本小數位數 + 2」位，後面全部縮成 S。
  3. 加減：用題目的進位制算（8 進位借 1 是借 8）。
  4. 正規化：整數部分只能有一位非 0 數字，不是的話移小數點並改指數。
  5. 捨入：看 G R S 套上面的規則。

05乘法硬體表格

每個 iteration 固定 3 行。5-bit 就做 5 個 iteration。

Multiplier：n bits　Multiplicand：2n bits　Product：2n bits（從 0 開始）負數直接用 2 補數；Multiplicand 左半補符號位（負數補 1）。
  1. 看 Multiplier 最右邊的 bit：1 → Product = Product + Multiplicand；0 → 什麼都不做。
  2. Multiplicand 左移 1 位（右邊補 0）。
  3. Multiplier 右移 1 位（左邊補 0）。
109 期中 Q8 · 5-bit，(−2)₁₀ × (−5)₁₀
−2 → 5 bits 00010 → 反轉+1 → 11110 → 補到 10 bits：11111 11110
−5 → 00101 → 反轉+1 → 11011（Multiplier）
只看 Product 右邊 5 bits：01010 = 10 ✓（−2 × −5 = 10）
黃底 = 這一行有變的那一格

考試時只要每一行只改一個欄位，就不會抄錯。投影片也有 Multiplicand 只補 0 的寫法（0000 1110），兩種 Product 右邊 n bits 都一樣。

06除法硬體表格

110、112、113 連續三年都考。112 年照這個寫拿 15/15。

Quotient：n bits = 0
Divisor：2n bits，除數放在「左半」，右半補 09 → 01001 00000
Remainder：2n bits，被除數放在「右半」29 → 00000 11101
總共做 n + 1 次（5-bit → 6 次）表格印到 7 也只做 6 次。
  1. Rem = Rem − Div。結果是負的，就寫 2¹⁰ − |差| 的 10-bit 二進位（最左 bit 會是 1）。
  2. 看 Rem 最左邊的 bit：
    是 1（負）→ 把 Div 加回去（Rem 變回上一行），Quotient 左移、最右補 0。
    是 0（≥0）→ Rem 不動，Quotient 左移、最右補 1。
  3. Div 右移 1 位。
偷吃步：先知道答案

09考前 5 分鐘小抄

效能

時間 = IC × CPI ÷ f
CPI = f(MHz) ÷ MIPS
MFLOPS = f(MHz) ÷ CPI(FP)
快幾倍 = 大時間 ÷ 小時間

Speedup

最高 = 原總時間 ÷（總時間 − 那一類）
能不能減 X%：那一類要 ≥ X% × 總時間

2 補數

正數前面補 0 → 全部反轉 → 最右位 +1
k bits 範圍 −2ᵏ⁻¹ ~ 2ᵏ⁻¹−1

Excess

真值 = 存的 − N
Excess 32 → 6 bits，Excess 64 → 7 bits

IEEE 754

1 | 8 | 23，bias 127
E=0：0.f × 2⁻¹²⁶
e < −126：左移 (−126−e) 位
總數 2³² − 2²⁴ − 1
gap = 2^(e−23)：最小 2⁻¹⁴⁹，最大 2¹⁰⁴

GRS

留原位數 + G + R，後面縮成 S（0/1）
大於一半進位，小於捨去
剛好一半：奇進偶捨

乘法表格

n 次，每次 3 行
最右位 1 → 加；Mcand 左移；Mplier 右移
答案看 Product 右邊 n bits

除法表格

n+1 次，每次 3 行
Div 放左半、Rem 放右半
減 → 負就加回補 0／正就補 1 → Div 右移
